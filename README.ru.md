> [!IMPORTANT]
> Загрузку файлов выполняет [aria2](https://aria2.github.io/); aria2t служит для него панелью управления. По умолчанию aria2t запускает и сопровождает собственный демон `aria2c`, поэтому настройка не требуется. Если указать уже работающий aria2, программа подключится к нему как обычный RPC-клиент. aria2t не собирает аналитику и телеметрию и взаимодействует по сети только с настроенным сервером aria2.

aria2t — консольный клиент для менеджера загрузок aria2, оформленный в палитре Tokyo Night. Он взаимодействует с aria2 по JSON-RPC: либо с приватным демоном, который запускает и сопровождает сам, либо с любым уже работающим aria2 на сидбоксе, NAS или удалённой машине. Все действия доступны как с клавиатуры, так и мышью, а приложение собирается в один статический бинарник на Go.

## ✨ Возможности

- **Добавляет всё, что принимает aria2** — зеркала URL, `.torrent`, `.metalink`, magnet-ссылки и input-файлы aria2.
- **Работает из коробки** — находит `aria2c`, запускает приватный демон и сопровождает его на протяжении всего жизненного цикла; внешний aria2 подключается флагом `--url`.
- **Управляет загрузками** — пауза и возобновление по одной или всех сразу, удаление, изменение порядка очереди, ограничение скорости отдельной загрузки или по расписанию.
- **Показывает подробности каждой загрузки** — карту частей, пиры и скорость зеркал, прогресс по каждому файлу, рейтинг и управление раздачей BitTorrent.
- **Проверяет целостность** — сверяет завершённый файл с контрольной суммой sha-256 и при несовпадении загружает его заново; ошибки описываются понятным языком, а не кодами.
- **Сохраняет состояние между запусками** — завершённые и текущие загрузки восстанавливаются, как и окно выбора файлов, закрытое без ответа.

## 📦 Поддерживаемые источники

`HTTP(S)` · `FTP` · `SFTP` · `BitTorrent` · `magnet:` · `.torrent` · `Metalink` · `input-файл aria2`

В aria2t можно добавить всё, что принимает aria2: обычные URL (несколько строк считаются зеркалами одного файла), magnet-ссылки и `.torrent` с поддержкой DHT и раздачи, `.metalink`, а также пакетный формат aria2 `--input-file` с отдельными опциями для каждой записи. Для многофайловых торрентов, magnet-ссылок и Metalink выбор файлов открывается до старта загрузки.

## 🧩 Как это работает

Файлы скачивает демон aria2, а интерфейс управляет им по JSON-RPC.

```
  Terminal                                  Your machine
  ┌──────────────────┐    JSON-RPC ws://    ┌──────────────────┐
  │      aria2t      │ ◀──────────────────▶ │  managed aria2c  │
  │  Bubble Tea TUI  │     push + poll      │ spawned · reaped │
  └────────┬─────────┘                      └────────┬─────────┘
           │                                         │ downloads · seeds
           │  ws:// or http(s)://                    ▼
           ▼                                ┌──────────────────┐
  ┌──────────────────┐                      │   HTTP mirrors   │
  │  external aria2  │─────────────────────▶│ BitTorrent · DHT │
  │  seedbox · NAS   │      downloads       │     Metalink     │
  └──────────────────┘                      └──────────────────┘
```

По умолчанию aria2t находит `aria2c` в `PATH` и запускает приватный демон на случайном порту со случайным секретом. Сессия сохраняется при выходе и восстанавливается при следующем запуске, а дочерний процесс корректно останавливается вместе с программой; демон, оставшийся после сбоя, завершается при следующем старте. Если указан внешний сервер, встроенный демон не запускается, и aria2t работает как обычный RPC-клиент.

## 📥 Установка

### Перед началом

- [aria2](https://aria2.github.io/) (`brew install aria2` / `apt install aria2`) — только для встроенного демона; для подключения к внешнему серверу не нужен.
- Терминал с поддержкой 256 цветов или truecolor. Мышь не обязательна: все действия доступны с клавиатуры.
- Go 1.25 или новее для сборки из исходников.

### Сборка и запуск

```sh
go build -o aria2t ./cmd/aria2t     # or: go install aria2t/cmd/aria2t
./aria2t
```

При первом запуске aria2t запустит приватный демон и откроет пустой список загрузок. Клавиша `a` открывает форму добавления, а `↵` добавляет ссылку из буфера обмена.

### Подключение к внешнему aria2

```sh
./aria2t --url ws://seedbox:6800/jsonrpc --secret mysecret
```

Конфигурация сохраняется в `~/.config/aria2t/config.json` (путь переопределяется флагом `--config`); управляемый демон хранит сессию в `~/.config/aria2t/daemon/`.

### Обновление

Пересоберите бинарник и замените старый. Конфигурация, правила планировщика и сессия демона хранятся в `~/.config/aria2t/` и при замене сохраняются.

### Удаление

1. Удалите бинарник.
2. Удалите каталог данных `~/.config/aria2t/` (конфигурация, сессия демона, логи).

## ⌨️ Работа с aria2t

**Добавление.** `a` открывает форму добавления, заполненную из буфера обмена. Несколько URI, по одному на строку, считаются зеркалами одного файла. Сочетание `^t` переключает вкладки (URL · `.torrent` · `.metalink` · input-файл), `^o` открывает выбор файла с диска, а `^s` добавляет загрузку приостановленной. На пустом экране первого запуска `↵` добавляет ссылку из буфера обмена.

**Выбор файлов.** Для многофайловых торрентов, Metalink и magnet-ссылок перед началом загрузки открывается дерево файлов с флажками; magnet-ссылка остаётся приостановленной, пока выбор не подтверждён. `space` отмечает файл или папку, `a` и `n` выбирают всё или ничего, `↵` подтверждает выбор. Изменить состав файлов позже можно клавишей `f`. Если выйти из программы до подтверждения, окно выбора откроется при следующем запуске.

**Список.** `tab` или клавиши `1`–`4` переключают вкладки All / Active / Waiting / Stopped. `space` приостанавливает и возобновляет выбранную загрузку, `P` и `U` делают то же для всех, `d` удаляет, `l` ограничивает скорость, `/` включает фильтр по имени, `y` копирует URL источника, `↵` открывает детали. На вкладке Waiting клавиши `J` и `K` перемещают выбранный элемент внутри очереди.

**Скорость.** `l` ограничивает скорость выбранной загрузки; значения выбираются из готовых пресетов. Глобальный лимит задаётся в настройках (`,`), сохраняется и повторно применяется после перезапуска демона. `S` открывает планировщик, где глобальные лимиты задаются по времени суток, например 5 MiB/s в рабочие часы и без ограничения ночью.

**Целостность.** На вкладке Stopped `c` сохраняет ожидаемую сумму sha-256, `v` сверяет с ней локальный файл, `R` загружает файл заново при несовпадении, а `X` очищает список.

Полный список сочетаний клавиш открывается по **`?`**. Все подсказки в нижней строке доступны и по клику мышью; в диалогах зелёная кнопка подтверждает действие, красная — отменяет.

## ⚙️ Конфигурация

`~/.config/aria2t/config.json` (пропущенные поля сохраняют значения по умолчанию):

```json
{
  "servers": [
    { "name": "built-in", "host": "localhost", "protocol": "ws", "managed": true },
    { "name": "seedbox", "host": "sb.example.net", "port": 6800, "secret": "…", "protocol": "wss" }
  ],
  "active": 0,
  "theme": "dark",
  "dir": "~/Downloads",
  "split": 16,
  "globalDown": "5M", "globalUp": "512K",
  "seedRatio": "1.5", "seedTime": "0"
}
```

Сервер с полем `managed` — это встроенный демон; порт и секрет выбираются при его запуске. Остальные записи описывают внешние серверы. `globalDown` и `globalUp` задают сохранённые глобальные ограничения скорости, `seedRatio` и `seedTime` — параметры раздачи по умолчанию; при подключении все эти значения повторно применяются к демону. Правила планировщика (`S`) также хранятся в этом файле.

## ❓ FAQ

**Что такое aria2 и зачем ему отдельный интерфейс?**
[aria2](https://aria2.github.io/) — быстрый движок загрузок с поддержкой HTTP(S), FTP, SFTP, BitTorrent и Metalink. Он работает в фоновом режиме, управляется по JSON-RPC и собственного интерфейса, кроме одноразовых команд, не имеет. aria2t добавляет к нему список загрузок в реальном времени, выбор файлов, управление очередью, ограничения скорости и проверку целостности.

**Чем это отличается от прямого запуска `aria2c`?**
`aria2c` либо скачивает файл и завершается, либо работает как демон, которым управляют скриптами. aria2t берёт управление демоном на себя: запускает его, сохраняет и восстанавливает сессию, корректно останавливает при выходе и завершает демон, оставшийся после сбоя. Поверх этого aria2t предоставляет интерактивный интерфейс.

**Работает ли он с aria2, который у меня уже запущен?**
Да. Флаг `--url ws://host:6800/jsonrpc --secret …` или встроенный переключатель серверов с замером задержек подключают aria2t к любому aria2 по WebSocket или HTTP(S), например на сидбоксе, NAS или в контейнере Docker. Встроенный демон в этом случае не запускается.

**Сохраняются ли загрузки после выхода из программы?**
Да. Управляемый демон сохраняет сессию при выходе и восстанавливает её при следующем запуске: активные, ожидающие, завершённые и раздающиеся загрузки восстанавливаются, а уже загруженные файлы распознаются и повторно не скачиваются. Окно выбора файлов, закрытое без ответа, также откроется снова.

**Можно ли выбрать файлы внутри торрента до начала загрузки?**
Да. Торренты, magnet-ссылки и Metalink добавляются приостановленными, и сначала открывается дерево файлов; magnet-ссылка приостанавливается после получения метаданных. Передача данных начинается только после подтверждения выбора, а изменить его позже можно клавишей `f`.

**Раздаёт ли он торренты?**
Да. Завершённый торрент продолжает раздаваться, а его статус меняется на seeding. Глобальные параметры раздачи — рейтинг и время — задаются в настройках и повторно применяются при каждом перезапуске демона.

**Клавиатура или мышь?**
Полноценно поддерживаются оба способа. Все подсказки в строке клавиш доступны по клику, а у каждого действия мышью есть клавиатурный эквивалент; полный список сочетаний открывается по `?`.

**Отправляет ли aria2t какие-либо данные наружу?**
Нет. Программа не собирает аналитику и телеметрию, не получает удалённую конфигурацию и взаимодействует по сети только с настроенным сервером aria2.
