> [!IMPORTANT]
> التنزيل نفسه يقوم به [aria2](https://aria2.github.io/)، وAria2t لوحة تحكّمه. يشغّل Aria2t افتراضيًا خديم `aria2c` خاصًّا به ويديره، فلا يلزم أي إعداد. ووجّهه إلى aria2 تُشغّله أنت فيتّصل به كعميل RPC عادي. لا يجمع Aria2t أي تحليلات أو بيانات استخدام، ولا يتحدّث عبر الشبكة إلا إلى خادم aria2 الذي تحدّده.

Aria2t مدير تنزيلات لـ aria2 بواجهتين: الطرفية والمتصفّح. يتحكّم في خديم خاص يشغّله لك، أو يتّصل عبر JSON-RPC بـ aria2 على seedbox أو NAS أو جهاز بعيد.

## ✨ المزايا

- **كل مصادر aria2:** مرايا الروابط، وملفات `.torrent` و`.metalink`، وروابط magnet، وملفات إدخال aria2.
- **إضافة المتصفّح:** إضافة Chrome ترسل تنزيلات المتصفّح وروابط magnet إلى الخديم نفسه، مع ترشيح بالحجم أو النطاق أو نوع الملف. ثبّتها من <https://aria2t.c0nn3ct.info/extension>.
- **خديم مُدار:** يجد Aria2t الملف `aria2c`، ويشغّل خديمًا خاصًّا، ويتولّى دورة حياته. استخدم `--url` للاتصال بخادم قائم.
- **التحكّم في التنزيلات:** إيقاف مؤقّت واستئناف وإزالة وإعادة ترتيب وحدود سرعة لكل تنزيل أو وفق جدول زمني.
- **تفاصيل التنزيل:** خريطة القطع، والأنداد، وسرعات المرايا، وتقدّم كل ملف، والنسبة، وأدوات البذر في BitTorrent.
- **فحوصات السلامة:** قارن الملف المكتمل ببصمة SHA-256، وأعد تنزيله عند عدم التطابق.
- **استعادة الجلسة:** استرجع التنزيلات النشطة والمكتملة بعد إعادة التشغيل، بما فيها اختيارات الملفات التي لم تُؤكَّد بعد.

## 📦 المصادر المدعومة

`HTTP(S)` · `FTP` · `SFTP` · `BitTorrent` · `magnet:` · `.torrent` · `Metalink` · `ملف إدخال aria2`

يستطيع Aria2t إضافة كل ما يقبله aria2: روابط عادية (وتُقرأ الأسطر المتعدّدة كمرايا للملف نفسه)، وروابط magnet وملفات `.torrent` بدعم DHT والبذر، وملفات `.metalink`، وصيغة الدفعات `--input-file` الخاصة بـ aria2 مع خيارات مستقلّة لكل مدخل.

## 🧩 كيف يعمل

خديم aria2 هو من ينزّل الملفات، وتتحكّم فيه واجهة أمامية عبر JSON-RPC. عميل الطرفية وإضافة المتصفّح واجهتان من هذا النوع، وكلتاهما تقودان الخديم نفسه.

```
  Front ends                                Your machine
  ┌──────────────────┐                      ┌──────────────────┐
  │ terminal client  │──┐  JSON-RPC ws://   │  managed aria2c  │
  │  Bubble Tea TUI  │  ├──────────────────▶│ spawned · reaped │
  └──────────────────┘  │   push + poll     └──────────────────┘
  ┌──────────────────┐  │                            │ downloads · seeds
  │ Chrome extension │──┘                            │
  │ capture · picker │                               ▼
  └────────┬─────────┘                      ┌──────────────────┐
           │  ws:// or http(s)://           │   HTTP mirrors   │
           ▼                                │ BitTorrent · DHT │
  ┌──────────────────┐      downloads       │     Metalink     │
  │  external aria2  │─────────────────────▶│                  │
  │  seedbox · NAS   │                      └──────────────────┘
  └──────────────────┘
```

يبحث Aria2t افتراضيًا عن `aria2c` في `PATH` ويشغّل خديمًا خاصًّا على منفذ عشوائي بسرّ عشوائي. تُحفظ الجلسة عند الخروج وتُستعاد في التشغيل التالي، وتُوقف العملية الابنة بنظافة مع البرنامج؛ وأي خديم بقي بعد انهيار يُغلَق في البداية التالية. وإن كان هناك خادم خارجي مُعَدّ، فلا يُشغَّل الخديم المدمج ويعمل Aria2t كعميل RPC عادي.

## 📥 التثبيت

### قبل أن تبدأ

- [aria2](https://aria2.github.io/) (`brew install aria2` / `apt install aria2`) — للخديم المدمج فقط؛ ولا حاجة إليه للاتصال بخادم خارجي.
- طرفية تدعم 256 لونًا أو الألوان الحقيقية. الفأرة اختيارية: كل إجراء متاح من لوحة المفاتيح.
- Go 1.25 أو أحدث للبناء من المصدر.

### البناء والتشغيل

```sh
git clone https://github.com/c0nn3ct-info/aria2t.git
cd aria2t/tui && go build -o aria2t ./cmd/aria2t
./aria2t
```

في أول تشغيل يبدأ Aria2t الخديم الخاص ويفتح قائمة تنزيلات فارغة. المفتاح `a` يفتح نموذج الإضافة، و`↵` يضيف رابطًا من الحافظة.

### الاتصال بـ aria2 خارجي

```sh
./aria2t --url ws://seedbox:6800/jsonrpc --secret mysecret
```

تُحفظ الإعدادات في `~/.config/aria2t/config.json` (ويمكن تغيير المسار بالخيار `--config`)، ويحتفظ الخديم المُدار بجلسته في `~/.config/aria2t/daemon/`.

### التحديث

أعد بناء الملف التنفيذي واستبدل القديم به. تبقى الإعدادات وقواعد الجدولة وجلسة الخديم في `~/.config/aria2t/` وتنجو من الاستبدال.

### إزالة التثبيت

1. احذف الملف التنفيذي.
2. احذف مجلد البيانات `~/.config/aria2t/` (الإعدادات وجلسة الخديم والسجلّات).

## ⌨️ استخدام Aria2t

**الإضافة.** المفتاح `a` يفتح نموذج الإضافة معبّأً من الحافظة. وتُقرأ عدّة روابط، كل واحد في سطر، كمرايا للملف نفسه. المفتاح `^t` يبدّل التبويبات (URL · `.torrent` · `.metalink` · ملف إدخال)، و`^o` يفتح مستعرض الملفات، و`^s` يضيف التنزيل موقوفًا. وفي شاشة التشغيل الأول الفارغة يضيف `↵` رابطًا من الحافظة.

**اختيار الملفات.** التورنتات متعدّدة الملفات وMetalink وروابط magnet تفتح شجرة ملفات بمربّعات اختيار، ويبقى رابط magnet موقوفًا حتى يُؤكَّد الاختيار. المفتاح `space` يحدّد ملفًا أو مجلدًا، و`a` و`n` يحدّدان الكل أو لا شيء، و`↵` يؤكّد الاختيار. ويمكن تغيير الاختيار لاحقًا بالمفتاح `f`. وإن خرجت قبل التأكيد فُتحت النافذة من جديد في التشغيل التالي.

**القائمة.** المفتاح `tab` أو المفاتيح `1`–`4` تبدّل تبويبات الكل / النشطة / المنتظرة / المتوقّفة. المفتاح `space` يوقف التنزيل المحدّد ويستأنفه، و`P` و`U` يفعلان ذلك للكل، و`d` يزيل، و`l` يحدّ السرعة، و`/` يرشّح بالاسم، و`y` ينسخ رابط المصدر، و`↵` يفتح التفاصيل. وفي تبويب المنتظرة يحرّك `J` و`K` العنصر المحدّد داخل الطابور.

**السرعة.** المفتاح `l` يحدّ سرعة التنزيل المحدّد، والقيم تُختار من إعدادات مسبقة. ويُضبط الحدّ العام في الإعدادات (`,`)، ثم يُحفظ ويُعاد تطبيقه بعد إعادة تشغيل الخديم. المفتاح `S` يفتح المجدول، حيث تُضبط الحدود العامة بحسب ساعات اليوم — 5 ميبي/ث في ساعات العمل وبلا حدّ في الليل، مثلًا.

**السلامة.** في تبويب المتوقّفة يخزّن `c` بصمة sha-256 المتوقّعة، و`v` يقارن الملف المحلي بها، و`R` يعيد التنزيل عند عدم التطابق، و`X` يفرّغ القائمة.

القائمة الكاملة لاختصارات المفاتيح تُفتح بالمفتاح **`?`**. وكل تلميح في الشريط السفلي قابل للنقر؛ وفي الحوارات يؤكّد الزر الأخضر الإجراء ويلغيه الأحمر.

## ⚙️ الإعدادات

الملف `~/.config/aria2t/config.json` (وكل حقل تحذفه يبقى على قيمته الافتراضية):

```json
{
  "servers": [
    { "name": "built-in", "host": "localhost", "protocol": "ws", "managed": true },
    { "name": "seedbox", "host": "sb.example.net", "port": 6800, "secret": "…", "protocol": "wss" }
  ],
  "active": 0,
  "theme": "dark",
  "dir": "~/Downloads",
  "split": 16,
  "globalDown": "5M", "globalUp": "512K",
  "seedRatio": "1.5", "seedTime": "0"
}
```

الخادم الذي يحمل الحقل `managed` هو الخديم المدمج، ويُختار منفذه وسرّه عند تشغيله. وتصف المدخلات الباقية خوادم خارجية. الحقلان `globalDown` و`globalUp` يضبطان حدود السرعة العامة المحفوظة، و`seedRatio` و`seedTime` معاملات البذر الافتراضية؛ وتُعاد كل هذه القيم إلى الخديم عند الاتصال. وقواعد المجدول (`S`) تُحفظ في هذا الملف أيضًا.

## ❓ أسئلة متكرّرة

**ما هو aria2 ولماذا يحتاج واجهة منفصلة؟**
[aria2](https://aria2.github.io/) محرّك تنزيل سريع يدعم HTTP(S) وFTP وSFTP وBitTorrent وMetalink. يعمل في الخلفية ويُتحكَّم فيه عبر JSON-RPC، وليست له واجهة خاصة تتجاوز الأوامر المفردة. ويضيف Aria2t قائمة تنزيلات لحظية، واختيار ملفات، وإدارة طابور، وحدود سرعة، وفحص سلامة.

**بماذا يختلف هذا عن تشغيل `aria2c` مباشرة؟**
الأمر `aria2c` إمّا ينزّل ملفًا ثم يخرج، أو يعمل كخديم تتحكّم فيه سكربتات. ويتولّى Aria2t إدارة ذلك الخديم: يشغّله، ويحفظ الجلسة ويستعيدها، ويوقفه بنظافة عند الخروج، ويغلق خديمًا بقي بعد انهيار. وفوق ذلك يقدّم Aria2t واجهة تفاعلية.

**هل يعمل مع aria2 أشغّله بنفسي؟**
نعم. الخيار `--url ws://host:6800/jsonrpc --secret …` أو مبدّل الخوادم المدمج مع قياس زمن الاستجابة يصل Aria2t بأي aria2 عبر WebSocket أو HTTP(S) — على seedbox أو NAS أو داخل حاوية Docker مثلًا. ولا يُشغَّل الخديم المدمج في هذه الحالة.

**هل تُحفظ التنزيلات بعد الخروج؟**
نعم. يحفظ الخديم المُدار جلسته عند الخروج ويستعيدها في التشغيل التالي: تُستعاد التنزيلات النشطة والمنتظرة والمنتهية والباذرة، ويُتعرَّف على الملفات المنزّلة سابقًا بدل تنزيلها من جديد. ونافذة اختيار الملفات التي أُغلقت بلا جواب تُفتح هي أيضًا مرة أخرى.

**أيمكنني اختيار ملفات معيّنة من تورنت؟**
نعم. تُضاف التورنتات وروابط magnet وMetalink موقوفة، وتُفتح شجرة الملفات أولًا؛ ويُوقف رابط magnet بعد وصول بياناته الوصفية. ولا يبدأ نقل البيانات إلا بعد تأكيد الاختيار، ويمكن تغييره لاحقًا بالمفتاح `f`.

**هل يبذر التورنتات؟**
نعم. التورنت المنتهي يواصل البذر وتتغيّر حالته إلى البذر. ومعاملات البذر العامة — النسبة والمدة — تُضبط في الإعدادات وتُعاد عند كل إعادة تشغيل للخديم.

**لوحة المفاتيح أم الفأرة؟**
استخدم ما تشاء. يمكنك النقر على كل إجراء في شريط المفاتيح، ولكل إجراء بالفأرة اختصار على لوحة المفاتيح. اضغط `?` لرؤية كل الاختصارات.

**هل يرسل Aria2t أي بيانات إلى أي مكان؟**
لا. لا يجمع البرنامج تحليلات ولا بيانات استخدام، ولا يجلب إعدادات بعيدة، ولا يتحدّث عبر الشبكة إلا إلى خادم aria2 الذي تحدّده.

## 🛠️ التطوير

تغطية العبارات في الوحدة **100%**، وهذا مفحوص تلقائيًا:

```sh
cd tui
go vet ./... && gofmt -l .
go test ./... -count=1 -coverprofile=cover.out -coverpkg=./...
go tool cover -func=cover.out | awk '$3!="100.0%"'      # must print nothing
```

لا شيء مستثنى من هذا الرقم، ولا شيء مكتوم: لا توجد في الشجرة أي توجيهات لتجاهل
التغطية. وحيث تبيّن أن بنية ما غير قابلة للوصول — عبارة محصورة بمنصّة لا يراها
ملفّ تعريف المنصّة الأخرى، أو مسار احتياطي استبعده شرط ثابت أصلًا — أُعيدت هيكلتها
بدل تخطّيها. وموقع الويب في `site/` يحقّق 100% على العبارات والفروع والدوال
والأسطر بالطريقة نفسها (`cd site && npm run test:coverage`).
